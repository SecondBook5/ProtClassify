# Artifacts

This folder holds non-code assets. Current layout:

- `legacy/` – historical models, arrays, and exploratory notebooks from the pre-refactor repo. They are preserved for reference but are **not** part of the current CAFA6 pipeline.

Going forward, keep new assets under the tracked locations described in `docs/PROJECT_STRUCTURE.md`:

- raw data → `data/raw/`
- processed arrays → `processed_data/`
- trained models → `models/`
- CAFA submissions → `submission/`
